*[AK]: Artifact Keeper, the open-source universal artifact registry these walkthroughs build on
*[RKE2]: Rancher Kubernetes Engine 2, Rancher's Kubernetes distribution
*[CNI]: Container Network Interface: the plugins that wire pod networking (canal in RKE2)
*[OCI]: Open Container Initiative: the image and registry formats container tools share
*[NEVRA]: Name-Epoch-Version-Release-Architecture, the full identity of an RPM package
*[TCG]: Tiny Code Generator, QEMU's software CPU emulator, used when KVM is not available
*[KVM]: Kernel-based Virtual Machine, Linux hardware virtualization (/dev/kvm)
*[PXE]: Preboot Execution Environment: booting a machine's installer over the network
*[MCP]: Model Context Protocol: how AI agents talk to tool servers
*[MCPB]: MCP Bundle: a zip with a manifest.json that packages one MCP server for one-click install
*[OIDC]: OpenID Connect: here, the short-lived ID token a CI job presents instead of a stored secret
*[CORS]: Cross-Origin Resource Sharing: the response headers that let a browser-based client read another origin
*[SSRF]: Server-Side Request Forgery: tricking a server into fetching an address of the attacker's choice
