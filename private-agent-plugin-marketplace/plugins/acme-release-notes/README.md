# acme-release-notes

Drafts release notes for an Acme service from the merged pull requests since the last tag,
grouped under Added, Changed, Fixed and Security, with anything that needs action first.

The same skill ships with three manifests, one per agent: `.claude-plugin/plugin.json` for
Claude Code, `.cursor-plugin/plugin.json` for Cursor and `.codex-plugin/plugin.json` for
Codex. The registry tags the version with all three and lists it in each agent's marketplace
document.

Owner: Acme Platform Team.
